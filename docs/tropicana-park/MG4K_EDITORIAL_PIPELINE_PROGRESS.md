**Дата обновления:** 09.11.2026  
**Целевое действие:** RAW/source → Tech Master без HDR → технический QA → визуальное утверждение → скачивание 16-bit TIFF → импорт в MG 4K с HARD-локерами → художественная обработка только по отдельному запуску.

## Как работает цепочка

1. **Upload:** HTTPS загрузка JPEG/PNG/WebP до 8 МБ; SHA-256, UUID, R2 object, персональная авторизация. Старые файлы не перезаписываются.
2. **Tech Master:** автономный Cloudflare Workflow → offline Container → OpenCV + tifffile → настоящий 16-битный TIFF-контейнер и full-resolution preview. **HDR запрещён.** Если исходник 8-битный, точность сигнала не становится RAW 16-bit.
3. **Progress:** `QUEUED` → `PROCESSING` → `TECHNICAL_QA_PENDING` → `AWAITING_HUMAN_QA`. Состояния записываются в R2 и переживают обновление страницы.
4. **Technical QA:** реальные файлы, контроль размеров, формат TIFF, SHA-256, source lineage, отсутствие HDR. Поддельный MIME не проходит.
5. **Human QA:** пользователь просматривает изображение, проверяет композицию, архитектурную геометрию, материалы и свет, принимает/отклоняет; решение необратимо для данной версии.
6. **TIFF Download:** доступен только после утверждения QA.
7. **MG 4K import:** утверждённый TIFF копируется из изолированного R2 в MG4K R2 с проверкой хеша; передаётся неизменяемый манифест HARD-локеров.
8. **Artistic generation:** MG4K получает одобренное JPEG-представление и серверный запрет ослабления локеров; запускается только отдельной командой с проверкой биллинга.

## Приёмочные ограничения

- **Нельзя утверждать качество визуальной геометрии автоматически**: произвольная коррекция перспективы, вертикалей и оптики здесь не производится; source сохранён, но архитектурный editorial требует отдельной обработки по утверждённой методике Perspective Lock.
- **Запрещено авторизовать генерацию или принять QA от имени человека.** Статус `AWAITING_HUMAN_QA` остаётся до решения пользователя.
- **Остаётся проверить вручную:** открыть пользовательскую QA-ссылку, просмотреть фото, выполнить Approve → Download TIFF → Transfer MG4K, затем по необходимости отдельно заказать платную художественную генерацию.
- При ошибке целостности, несовпадении SHA или неверной геометрии — HOLD / REJECT и новая версия, без перезаписи архива.

**Контрольная точка:** реальный 16-битный TIFF ранее загруженной фотографии сформирован и архивирован. Принятие качества и разрешение художественной обработки — только после визуального решения пользователя.
