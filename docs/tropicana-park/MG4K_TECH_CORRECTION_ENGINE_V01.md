# MG 4K / «Тропикана-парк» — Technical Correction Engine v0.1

**Дата:** 10 ноября 2026. **Целевое действие:** после REWORK_REQUESTED автоматически сформировать реально изменённую техническую V2, с доказательствами цифровой коррекции, версионным архивом и повторным человеческим QA. **Этап:** разработка/CI; публикация — только после прохождения релизных гейтов.

**Прогресс:** не использовать старые 97% как готовность коррекции. Предварительная оценка полного технического конвейера — **около 60%**: успешно реализованы source integrity, нейтральный TIFF, версионирование, ограниченная коррекция света/цвета и human QA, но не выполнены универсальная оптика/перспектива и полноценный RAW для новых снимков. Доля не является автоматической метрикой тестов.

## Поддерживаемое сейчас

| Категория замечаний | Автоматическая коррекция | Строгое ограничение |
| --- | --- | --- |
| Свет / экспозиция | Измеримый глобальный сдвиг до 0.30 EV | Только медиана яркости вне диапазона .18–.76, исключены экстремальные/неоднозначные сцены |
| Цвет / баланс белого | RGB-гейны на проверенном нейтральном участке от 0.93 до 1.07 | Не менее 3% подходящих нейтральных пикселей, измеримый сдвиг |
| Оптика, вертикали, перспективная геометрия | **HOLD** без откалиброванного профиля и опорных точек | Запрещено автоматически предполагать структуру здания |
| Детали / шум, материалы, фактуры | **HOLD** до объективного профиля и независимых критериев | Запрещено изменять фактуры без доказанной необходимости |
| Изображение без значимой технической ошибки | **HOLD** | Изображение не переименовывается в «исправленное» без изменения пикселей |

Все операции — детерминированные по оригинальным пикселям и сохраняют исходные размеры и геометрию; HDR, дополнительные виртуальные экспозиции, генерация и платные вызовы OpenRouter запрещены. Cloudflare Compute и R2 могут тарифицироваться отдельно.

## Версионный контур

1. Пользователь возвращает **V1** с обязательной категорией и конкретными замечаниями. Решение SHA-bound и неизменно.
2. Кнопка **«Запустить безопасную коррекцию»** доступна только для `exposure` и/или `color`. Для других категорий интерфейс показывает **HOLD** и точную причину — невозможность подтвердить коррекцию оптики или перспективы без опорных данных.
3. `POST /api/editorial/job/rework/auto` проверяет полномочия, исходную QA V1, категории, отсутствие уже созданной версии, создаёт отдельную **V2** со ссылкой на **тот же неизменный исходный файл** и с подписанной SHA цепочкой замечаний, V1 master SHA, контрольной схемой и запретами.
4. Cloudflare Workflow поднимает отдельный offline Container без Internet/OpenRouter. Технический Python применяет только измеримые глобальные поправки, делает реальный 16-bit TIFF, браузерный JPEG, QA JSON с диапазонами и измерениями.
5. Если нет объективного основания/пропусков/цветовых нейтральных участков, результат **HOLD** — никакой `TECHNICAL_QA_PASS`, `APPROVED`, скачивания и MG4K handoff.
6. При доказуемой корректировке обновляется QA V2: другой SHA TIFF относительно V1, `changed_mean_absolute_fraction>=0.003`, `operations` и неизменная связь source/parent/remarks, `HDR_applied=false`. **Human QA всё равно PENDING**, V2 сравнивается с V1, утверждается только человеком.
7. При HOLD V2 можно продолжить как V3 через ручную загрузку действительно исправленного исходника, не удаляя V1/V2/историю.

## Технический контракт

- Источник V1/V2: immutable R2 key + SHA-256, исходное цветовое число бит (8-битный PNG не превращается в новый 16-bit RAW-сенсорный сигнал).
- Коррекция: `correction_plan` внутри нового `job.json`: `DETERMINISTIC_TECH_REWORK`, allowed categories, parent ID, parent master SHA, remarks SHA, `geometry_transform=IDENTITY`, `HDR_allowed=false`.
- Результат: независимые `technical/master16.tif`, `technical/fullres-preview.jpg`, `technical/qa.json` V2 с R2 SHA and TIFF signature.
- Human QA и `handoff.json`: только после explicit **APPROVED** к конкретной версии SHA, не при upload/rework.
- Условия отказа: `geometry`, `detail`, `materials`, отсутствие подтверждённых neutral samples, нет отклонения экспозиции, превышен предел clip fraction 0.007, нет значимой разницы, mismatch SHA, отсутствует permission — **HOLD/409**, без подмены.
- Гарантии сохранности: V1 и ранее утверждённые архивы DSC09818 RAW/TECH V9/V10 и Editorial 01 не модифицируются.

## Проверки и выпуск

- `tests/editorial-auto-rework.py`: синтетические PNG с измеримым затемнением и цветовым сдвигом → **настоящий отличающийся TIFF/preview и доказательства SHA**; сбалансированный кадр, запрещённый HDR, перспективные искажения без данных → HOLD.
- `tests/editorial-jobs.test.mjs`: auth, неизменность V1, новая V2 со старым источником, запрет handoff до человеческого QA, повторный запуск и восстановление после HOLD в следующую версию.
- `Editorial Photo CI`, `4K Upscaler Regression Guard` — обязательны на финальном commit.
- Проверка в production на **синтетическом** техническом изображении после деплоя не должна создавать human APPROVED или платный генеративный job.

**Невыполненный следующий приоритет — Geometry Engine:** проверенный профиль объектива или корректные линии/опорные точки, проектная гомография с действительной проверкой маски и архитектурной непротиворечивости, нейтральная RAW-проявка без HDR. Для текущего PNG нельзя достоверно угадать camera/lens distortion. Не заявлять автоматическую архитектурную коррекцию до независимой QA и real RAW/anchors acceptance.
